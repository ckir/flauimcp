## Upstream & Ecosystem Acknowledgements

FlaUI.Mcp is built upon the following open-source projects and foundational libraries:

* **[FlaUI](https://github.com/FlaUI/FlaUI)** by [Roemer](https://github.com/Roemer) and contributors:
  The powerful .NET UI Automation library that serves as the core perception and pattern-interaction engine for FlaUI.Mcp.
* **[Model Context Protocol C# SDK](https://github.com/modelcontextprotocol/csharp-sdk)** by Microsoft and the MCP working group:
  The standard C# implementation of the Model Context Protocol.
* **[Pester](https://github.com/pester/Pester)**:
  The ubiquitous BDD testing framework for PowerShell that powers repository quality gates and release smoke verification.
* **[PolyForm Project](https://polyformproject.org/)**:
  Providing clean, plain-language source-available licensing standards.
