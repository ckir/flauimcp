FlaUI.Mcp

Supervised Windows Automation for AI Agents

FlaUI.Mcp connects AI drivers like Claude Code and Antigravity to native Windows UI Automation 3 (UIA3). It translates high-level MCP requests into deterministic accessibility tree queries, pattern interactions, and OS actuation behind strict operator safety guardrails and zero-leak privacy shields.

Architecture & Safety Philosophy

AI agents are probabilistic engines. Operating system actuation requires zero-trust guardrails.

OS Actuation Danger Notice

⚠️ Software with real OS actuation power. Synthetic input is locked by default. There is no sandbox. FlaUI.Mcp executes real Windows Win32 / UIA3 actions on your interactive desktop session. Read the full danger model before installing.

  • PRIVACY SHIELD

    Zero-Leak Redaction

    Password fields are masked automatically across accessibility tree reads, text extractions, element diffs, and screenshot pixels. Operators can also define custom regex redaction patterns for proprietary keys and sensitive tokens.

  • DEFAULT LOCKED

    Zero-Trust Synthetic Input Leases

    The server starts strictly in read-only perception mode. Synthetic mouse clicks, mouse drags, and keyboard typing are locked until an operator explicitly grants a timed lease (e.g. 10m) via CLI or hotkey.

  • AUDIT TRAIL

    Supervised Non-Determinism

    Complete tamper-evident audit logging (logs/session.log) captures every agent command, automation ID lookup, click coordinate, and lease grant for enterprise accountability and post-incident analysis.

  • UIA3 PRECISION

    Native UIA3 Precision

    Directly queries Windows UI Automation 3 element handles and automation IDs rather than brittle pixel guessing with vision models. Enjoy reliable bounding rectangle calculations and invoke patterns across modern and legacy apps.

How It Works

An authoritative, strongly-typed bridge between LLM agent drivers and the native Windows desktop.

  • PROTOCOL BRIDGE

    Standard MCP Stdio Bridge

    FlaUI.Mcp acts as an RPC bridge between standard Model Context Protocol (MCP) stdio streams and the native Windows UI Automation API. AI clients send standard JSON-RPC tool invocations that execute directly against local Win32 runtime targets.

  • SCHEMA RESOLUTION

    Element Targeting Schema

    The schema handles top-level windows, nested child controls, buttons, edit inputs, combo boxes, menus, and custom controls. Elements are queried via AutomationId, Name, ClassName, or control type with deterministic handle caching.

  • LEASE VERIFICATION

    Input Lease Security

    Before any synthetic OS event is dispatched to the system message queue, FlaUI.Mcp checks the active tokenized input lease. If the lease is expired or missing, actuation is safely rejected while read-only perception remains active.

  • SUPERVISED RUNTIME

    Tamper-Evident Ledger

    Every perception read, redaction mask, lease verification, and actuation invoke is timestamped and written to an append-only session ledger, giving operators full visibility into agent actions on the interactive desktop.

Installation & Operator Quickstart

Get up and running with FlaUI.Mcp in less than two minutes with automated CLI registration.

  1. Download flaui-mcp-setup.exe from the latest official GitHub release.
  2. Run the installer. Windows SmartScreen may note that it is unsigned — select More info → Run anyway. The installer automatically registers FlaUI.Mcp with Claude Code and Antigravity CLIs.
  3. Restart your AI agent terminal to reload the tool catalog, or manage operations with the commands below.
  • Silent Setup flaui-mcp-setup.exe --silent Perform an unattended installation and auto-register with Claude Code and Antigravity CLIs.
    Copied!
  • Claude Code Registration claude mcp add flauimcp -- flaui-mcp.exe Manually register the FlaUI.Mcp server binary with your local Claude Code tool environment.
    Copied!
  • Grant Synthetic Lease flaui-mcp lease grant --duration 10m Unlock synthetic OS mouse clicks and keyboard typing for 10 minutes before auto-locking.
    Copied!
  • Check Server Status flaui-mcp status Verify server health, active lease duration, and target desktop session details.
    Copied!
  • Revoke Synthetic Lease flaui-mcp lease revoke Immediately revoke active input lease, returning FlaUI.Mcp to strict read-only lock.
    Copied!
